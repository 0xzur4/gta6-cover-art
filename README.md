Neon Palms Cover Studio — an offline web app that turns a photo and a caption into GTA 6-style cover art (multi-panel poster, bold lettering, Vice City sunset/neon grade), exported as PNG.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080, load a photo, pick a layout and grade, and export the cover as PNG.
